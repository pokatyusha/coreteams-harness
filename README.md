# CoreTeams — общая обвязка команды

Координация через GitHub Issues между обвязкой Кати и профилями Арины, Филиппа и Димы. Запуск только вручную, один ограниченный проход по явно указанному Issue. Фоновых процессов, расписаний, webhooks, Actions и слияний в этом пакете нет.

**CoreTeams — Рабочее пространство с AI-командой для сложных задач вне одной экспертизы.**

## Подключение

1. Получить доступ к приватному [репозиторию](https://github.com/pokatyusha/coreteams-harness).
2. Следовать [инструкции подключения](docs/connect.md), выбрать свой профиль.
3. Заполнить локальную привязку и проверить её. Опубликованный профиль ещё не означает подключённого исполнителя.
4. По команде владельца обработать один адресованный Issue по [протоколу](docs/exchange.md).

Свои компонентные скиллы оформляйте по [инструкции с полным шаблоном и связями](docs/write-skills.md). Общий скилл обмена переиспользуется, API продукта не дублируются.

| Адрес агента | Владелец | Профиль |
|---|---|---|
| `arina-storage` | Арина | [Storage](profiles/arina.md) |
| `filipp-infra` | Филипп | [Сборка и инфраструктура](profiles/filipp.md) |
| `dima-gateway` | Дима | [Gateway и контракты](profiles/dima.md) |
| `coordinator` | Катя | Координация, адресация и приём результата; правила в AGENTS.md |

## Источники и границы

Код продукта остаётся в `AcryCxde/PP-Sber-Autumn-2026`. Этот репозиторий хранит профили и правила передачи работы, не копию продукта. API компонентов и соответствие версий фиксируются в продуктовых документах; здесь передаются точные ссылки и SHA. Существующий [PR #12](https://github.com/AcryCxde/PP-Sber-Autumn-2026/pull/12) — точка поиска контрактных документов, не доказательство их согласования.

Личная обвязка Кати `project-harness` остаётся отдельной: её приватный контекст и другие направления сюда не переносятся. Участники сохраняют свои локальные инструкции и инструменты. [Карта связей](docs/architecture.md) отделяет обмен агентов от API продукта.

## Проверка пакета

Нужен Python 3.10+; сторонних зависимостей нет.

```text
python scripts/validate.py
python -m unittest discover -s tests -v
git diff --check
```

Проверка сообщения: `python scripts/validate.py --message templates/request.json`.
Локальная привязка: `python scripts/validate.py --binding .local/binding.json`.

Результаты создания пакета: [verification.md](docs/verification.md). Реальная связь с компьютерами участников и продуктовый E2E требуют отдельных подтверждений.
